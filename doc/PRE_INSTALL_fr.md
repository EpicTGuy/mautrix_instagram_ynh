* Une instance Synapse doit être installée sur le serveur.
* L'**administrateur de la passerelle** doit être un seul compte Matrix (ex. `@jean:exemple.fr`). Ne remettez pas ce même compte dans le champ **utilisateurs autorisés** : indiquez-y plutôt le nom de votre serveur (ex. `exemple.fr`) pour autoriser tous les comptes locaux.
* La connexion se fait depuis la discussion avec le robot, par identifiant et mot de passe (double authentification gérée) ou avec les cookies de votre navigateur sur instagram.com. Instagram ne propose pas de connexion par QR code. Meta peut signaler ou bloquer temporairement les comptes utilisant des clients non officiels : à vos risques.
