* Une instance Synapse doit être installée sur le serveur.
* L'**administrateur de la passerelle** doit être un seul compte Matrix (ex. `@jean:exemple.fr`). Ne remettez pas ce même compte dans le champ **utilisateurs autorisés** : indiquez-y plutôt le nom de votre serveur (ex. `exemple.fr`) pour autoriser tous les comptes locaux.
* La connexion se fait avec les **cookies de votre navigateur sur instagram.com** (la connexion par mot de passe nécessite une webview et n'est disponible que via mautrix-manager). Meta peut signaler ou bloquer temporairement les comptes utilisant des clients non officiels : à vos risques.
* Documentation upstream : <https://docs.mau.fi/bridges/go/instagram/index.html> — salon d'aide : `#instagram:maunium.net`
