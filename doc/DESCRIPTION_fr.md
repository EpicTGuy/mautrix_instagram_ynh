Passerelle Matrix pour les messages privés Instagram, basée sur la passerelle officielle [mautrix-instagram](https://github.com/mautrix/meta) (Go, bridgev2).

La passerelle est un service d'application Synapse et repose sur une base PostgreSQL. Vos messages privés Instagram apparaissent comme des salons Matrix : vous pouvez les lire, y répondre, réagir et envoyer des médias depuis n'importe quel client Matrix (Element, FluffyChat…).

Depuis mautrix-meta v26.08, Instagram est géré par le binaire dédié `mautrix-instagram` ; le binaire `mautrix-meta` ne gère plus que Facebook Messenger.
